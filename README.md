# rokurooooo01.github.io

Simple static GitHub Pages site (HTML/CSS/JS).

## Repository setup
- This repository name already matches a personal GitHub Pages site (`rokurooooo01.github.io`).
- Publish from the `main` branch root folder.

## Local structure
- `index.html` - homepage
- `css/style.css` - styles
- `js/main.js` - small client-side behavior
- `images/` - image assets + favicon

## Enable GitHub Pages
1. Open **Settings > Pages** in this repository.
2. Under **Build and deployment**, set:
   - **Source**: *Deploy from a branch*
   - **Branch**: `main` and `/ (root)`
3. Save and wait for deployment.

Your site URL will be: `https://rokurooooo01.github.io/`

## Verify and iterate
- Open the URL on desktop and mobile.
- Commit and push updates to `main`; GitHub Pages redeploys automatically.

## Optional improvements
- Add a custom domain in **Settings > Pages** and create matching DNS records.
- Keep metadata (`title`, description, social tags) updated for SEO.

# HOW TO ADD YOUR LATEX PDF (30 seconds):
#   1. Compile your book locally, e.g.  pdflatex main.tex
#   2. Copy the output here as:
#        assets/foundational-mathematics.pdf
#      (keep exactly this name — the book page links to it)
#   3. Commit + push:
#        git add assets/foundational-mathematics.pdf
#        git commit -m "Update textbook PDF"
#        git push origin main
#      The page shows it instantly: embedded preview + Download button.
#
# OPTIONAL — versioned copies (recommended at release time):
#   Copy the same file to e.g.
#     assets/foundational-mathematics-v0.1.0.pdf
#   so readers can cite an exact version. The page always serves
#   the unversioned foundational-mathematics.pdf as "latest".
